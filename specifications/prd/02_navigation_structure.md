# Navigation

## Bottom tabs (5)
| Tab | Purpose |
|-----|---------|
| Home | Featured event, stats, announcement, Scan QR, notification bell |
| Events | Upcoming \| Past |
| Badges | Catalog (greyed unearned) |
| Skills | Published skills |
| Profile | Stats, Members, Notifications, settings, admin |

## Home
- **Scan QR** button (primary)
- **Bell icon** → notification inbox (no unread badge in MVP)
- **Admin:** if no upcoming events, show **Create event** CTA (admins only)

## Profile
- Row: **Members** → directory list
- Row: **Notifications** → same inbox as bell
- **Admin panel** (admins only)

## Events
- Sub-tabs: **Upcoming** | **Past**
- Tap event → Event detail

## Not in MVP
- 6th tab for directory or inbox
