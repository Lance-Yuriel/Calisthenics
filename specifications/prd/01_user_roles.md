# User Roles

## Member (approved)
- Home, Events (upcoming/past), Badges, Skills, Profile
- **Member directory** (names + roles)
- RSVP: `GOING` | `NOT_GOING` | `WAITLIST`
- QR scan (global + event detail)
- Edit profile: name, photo, bio

## Admin
- All member capabilities
- Admin panel: members, events, notifications, badges, skills
- Event lifecycle + QR print/show
- Approve/reject/re-apply handling for pending
- Manual attendance, badge assign/revoke

## Pending / rejected
- **Pending:** waiting screen only
- **Rejected:** blocked; can re-apply → pending

## Bootstrap
- First admin via Firebase console
