# Home Screen

## Featured event
- **LIVE** first, else soonest **upcoming** (`PUBLISHED`/`LIVE`, not `CANCELLED`).
- Card: title, time, location snippet, RSVP chip, countdown to **check-in open** (60 min before `startAt`).
- Tap → event detail.

## Empty upcoming (no featured event)
- **Members:** card “No upcoming sessions” + link to **Past** tab.
- **Admins:** same empty card **plus** prominent **Create event** button.
- Stats row and announcement card **still visible**.

## Quick stats
- Attendance total | Badges earned | Upcoming GOING count

## Latest announcement
- Latest `announcement`-type notification (title + snippet).
- Tap → inbox filtered or detail.

## Actions
- **Scan QR** (primary button)
- **Bell** → inbox (no unread count/dot in MVP)
