# Skills Explorer

## Content per skill
- `name`, `category`, `difficultyTag`, markdown `description`
- Optional `imageUrl`, `videoUrl` (embed)
- `order`, `published` boolean

## Visibility
- **Published:** visible to approved members.
- **Unpublished:** **admin preview only** — hidden from members.

## Progression (MVP)
- Flat list by category + difficulty tags (no prereq graph).

## Admin
- CRUD + reorder + publish toggle.
