# Profile & Settings

## Editable fields
- Display name
- Profile photo (Firebase Storage)
- Bio — max **280** characters

## Read-only
- Attendance count, badges earned, role label
- Upcoming GOING count (optional duplicate of home)

## Rows
- **Members** → directory (`17_member_directory.md`)
- **Notifications** → inbox (shared feed)
- **Admin panel** (if admin)
- Sign out

## Other member profile (from directory tap)
- Read-only: photo, name, role, bio, badges earned
- No edit, no contact actions
